# 主界面美术资产

当前可玩 Phaser 桌面的资产说明。美术样本是用户提供的风格参考，不作为世界规则。

## 已使用

- `public/assets/reference.png`：原始用户样本，未改动。Phaser 在运行时通过 texture frames 取肖像和两幅事件插画；没有把整张带文字样本当游戏背景。
- `public/assets/desk.png`：内置 imagegen 根据样本材质生成的无文字背景。真实数字、标签、角色状态、筹码和事件由 Phaser 单独绘制。
- `public/assets/ui.png` + `ui.json`：界面图集（Phaser JSON hash，63 帧，每帧 128×128）。由 `art/ui/` 下的 SVG 源经 `npm run art`（`scripts/build-atlas.mjs`，sharp）栅格化生成；产物已提交，`npm start` 不依赖 sharp。改 SVG 后重跑脚本并一并提交产物。
- `public/assets/grain.png`：256×256 可平铺纸纹，Phaser 以 TileSprite 叠在纸面面板上。源为 `art/ui/frames/grain.svg`。
- 声音：`client/audio.ts` 用 Web Audio 合成拿牌、落牌、执行、揭示及错误提示。是 Demo 反馈音，没有冒充原创录制音效或正式配乐。

## 图集约定

- `art/ui/icons/*.svg`：单色图标，viewBox 96×96。只用 `#ffffff`（主色）和 `#b4b4b4`（暗部），运行时由 Phaser `setTint` 乘色：纸面用墨色，深蓝面板用奶油色或青色，危险用红色。图标里不放文字和数字。
- 分组：`res-*` 三条资源；`card-*` 七种筹码与空槽；`role-*` 八个岗位；`ev-*` 八种事件原型（与 `EVENT_PROTOTYPES` 同名）；`verb-*` 与 `talk` 对应行动意图；`fact-*` 对应结构化事实牌（档案目前显示字段摘要，四种牌面图标尚未铺开）（目击/出入/声明/资源提取）；其余为状态与界面（duty/off/dead/pin/attend/energy/clock/penalty/reward/person/fatigue/evidence/menu/sound-*/airlock）。
- `art/ui/frames/medallion-{navy,paper,red,green}.svg`：全彩铜圈底座，不着色，图标叠在中央。
- `chip-<角色>`：圆形肖像筹码，由脚本从样本裁切（坐标见 `art/ui/portraits.json` 的 `chips`）并套 `chip-ring.svg`。大肖像和筹码统一读取此配置。大肖像在桌面、派遣面板和报告中等比例缩放、居中留边，避免拉伸；后四位的裁切已避开样本休息字样并保留头部。更换源图后需更新 `source`、`rects` 与 `chips` 并重新构建；若改变运行时源路径，还需加入服务器静态白名单。单人正式肖像需先拼成无文字源图；当前构建不自动拼接八个独立文件。
- 航程报告和记录卡复用 `grain.png` 纸纹、`res-*` 资源图标及 `chip-*` 人物筹码。名单用中性色标签，资源增减分别用绿、红色标记；未增加图片或修改图集。
- 无逾期代价的限时机会复用 `ev-cache` 与绿色铜章，关闭日期用绿色显示；办法页写明错过不扣资源。危机仍显示红色到期提示，不新增素材。
- `art/ui/contact-sheet.png`：所有帧在深蓝/纸面两种底色上按运行时方式着色的预览，用于审图，不被游戏加载。
- 客户端规则：资源、事件条件（期限/逾期惩罚/人手/所需筹码/奖励）、筹码种类、行动意图、船员当值及派遣状态用图标表达；疲劳图标仅历史保留，不再显示；完整规则句子只在悬停提示和弹层中出现。事件卡正文使用服务端投影的 `brief`（原始短描述），条件由结构化字段生成。

## 当前素材限制

样本只有一张合成图，肖像分辨率有限；休班头像本身带灰色处理。仓储官暂用样本的驾驶员肖像，书记员暂用导航员肖像，标签使用本项目真实角色。右侧事件插画临时用于非氧气事件，不能把图中太阳风当作真实事件规则。此映射只是 Demo 占位，不是最终角色设定。

后续可提供以下独立文件，保留现有界面与规则即可替换：

| 优先级 | 文件 | 要求 |
|---|---|---|
| 首先 | 八位船员肖像 | 每人独立 512×640 PNG/WebP，胸像、统一光照，无文字/牌框/休班灰度；科学家、工程师、安保官、仓储官、医官、通讯员、书记员、厨师 |
| 其次 | 事件插画 | 氧气泄漏、配电故障、库存异常、调查线索，各 800×450，无文字 |
| 可选 | 界面装饰 | 空白纸牌、金属牌框，透明 PNG；保留可拉伸安全边距。图标已由 `art/ui/icons` 覆盖，如需手绘风格可按同名帧替换（128×128 白色透明 PNG 或 SVG） |
| 可选 | 事件原型插画 | 若要按事件类型区分插画，按 `ev-*` 八种各一张 800×450，无文字 |
| 可选 | 音频 | 纸牌拿取/落位、舱门、通讯、警报，短 WAV/OGG；一条可循环舱内环境音 |

背景生成方式：OpenAI 内置 imagegen，参考原图。生成提示要求保持暖铜/深蓝工业科幻绘画，中央留空星图桌面、下沿留空深色桌面、上沿舷窗与星球；无人物、卡牌、文字、数字、按钮。完整提示见 `背景生成提示.txt`。

## 资产盘点与替换次序

| 资产组 | 数量/状态 | 运行入口 | 下一步 |
|---|---|---|---|
| 资源、筹码、岗位、事件、行动、状态图标 | 51个SVG，机制覆盖通过 | `ui.png/ui.json` | 可按同名帧替换画风 |
| 铜章底座 | 4帧 | 图集 | 已接入事件台 |
| 圆形肖像筹码 | 8帧，参考图占位 | 图集 `chip-*` | 随正式肖像替换 |
| 纸纹 | 256×256 | `grain.png` | 已接入面板 |
| 桌面背景 | 现有无文字生成图 | `desk.png` | 沿用现有背景 |
| 事实图标 | 4帧包含在53个图标内 | `fact-*` | 历史兼容保留；当前桌面改为航程记录，不再发放文字证据 |
| 大肖像 | 8个裁切，共用`portraits.json` | 参考图texture frames | 第一优先：8张512×640正式肖像 |
| 事件插画 | 2幅参考图裁切，不等于8类完整素材 | `reference` frames | 第二优先：按8种`ev-*`各800×450 |
| 声音 | 5类合成反馈，非录制素材 | `client/audio.ts` | 短音效与循环环境音 |

替换肖像时同时维护 `rects` 和 `chips`；目前是单一源图，不会自动拼接独立文件。若更改源图URL，必须更新服务器静态白名单。每次替换后执行 `npm run art`、`npm run art:check`、`npm run build` 并查看大肖像及筹码实图，避免只更新了其中一套。

自动检查可复现：`npm run art:check`。65帧、全部角色、事件原型、筹码、四种事实字段覆盖已通过；来源不是正式角色定稿。浏览器验证范围与已知限制见 [当前实施设计](../guysfall_当前设计.md)。
