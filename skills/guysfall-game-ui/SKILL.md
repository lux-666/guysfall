# 七日寄生游戏桌面

先查看 `public/assets/reference.png`，再查看当前实际画面。用户选定 Phaser；只完善一个主游戏桌面，不扩展网站页面。

## 视觉与空间

- 1600×1000 设计画布，Phaser FIT 缩放；桌面横屏优先。保留中央事件台、上沿三处维护岗位、左谈话、右气闸、下沿八张船员牌、底部筹码及证据入口。同屏完成布牌，无文档式纵向滚动。
- 冷蓝钢板和星图、暖铜边缘、奶油纸张、局部绿当值/红危险。背景是有材质的环境，人物是有肖像的物件。参考样本不是可直接点击的整张 UI 截图。
- 构图主次依次为事件、船员、执行；维护位是紧凑插槽。证据、历史、详细规则按需展开；不要把说明全部常驻在桌面。
- 样本是美术依据，不是游戏规则：实际为七天、三条资源、Energy 3、既有八个角色。不得照抄样本的 28 天、Energy 6 或驾驶员/导航员岗位。
- 文字和数值由游戏绘制，不烘焙到图片里。图标、铜章和肖像筹码来自 `ui` 图集（`npm run art` 由 `art/ui` SVG 生成）；大肖像和事件图目前采用样本的 Phaser texture frames；美术来源、映射与替换要求见 `docs/art/资产说明.md`。

## 交互

- 人物和筹码同时支持拖放及点击；拿起、合法目标提示、落位、非法退回、撤回都须可见。物资投入到具体执行者，不能变成脱离人物的资源按钮。
- 人物位置按身份固定，不随隐藏状态变化。休班、当值、已派遣、死亡和选中都有不同表现。
- UI 只消费服务端玩家投影；服务端裁定规则、身份、证据和结果。不让客户端读取全量私有存档。
- 使用 stable id 维护草稿；SSE 重连、执行中快照、请求失败不能丢弃本日未执行草稿；进入新日/新局才清空。
- 执行中锁住派遣及新局；气闸指令在真正提交前明确永久后果。声音在用户交互后启用，可关闭。
- 弹层只阻挡当前桌面，ESC 可关；超过一屏的事件、报告和证据必须分页，不能截断后无法读取。

## 验收

运行 `npm run typecheck`、`npm test`、`npm run build`。在隔离存档的固定策略模式检查实际画面与一整日循环：拿牌、落位、筹码唯一性、亲临预算、撤回、结算、报告、次日轮换、刷新恢复。没有操作真实 Agent 就不要声称验证过。

对照样本验收材质和构图；自动测试通过不等于视觉或拖放已通过。需要美术补充时索取具体尺寸/透明通道/对象，先完成已有资产能支持的交互。
